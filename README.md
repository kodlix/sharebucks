# ShareBucks Frontend

Implement the frontend for the attached ShareBucks specification. Put it in frontend/ and centralize all backend calls in one mock service layer for now. Make the UI fully interactive with all key MVP features: authentication, group creation/discovery/membership, expense tracking with equal and custom splits, balance calculations, settlement suggestions, recording full/partial settlements, and dashboard summaries.
